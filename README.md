# STYLE — киім дүкені

Қарапайым киім дүкенінің сайты: каталог, іздеу, категория сүзгісі, себет және тапсырыс беру.

## Құрылымы

```
style-shop/
├── index.html      # Басты бет және каталог
├── cart.html       # Себет және тапсырыс формасы
├── css/style.css   # Стильдер
├── js/script.js    # Тауарлар, каталог, себет (localStorage)
├── php/order.php   # Тапсырысты қабылдап, MySQL-ге жазады
├── php/config.example.php  # Дерекқор баптауы (config.php деп көшіру керек)
└── db/
    ├── schema.sql  # Кестелер + бастапқы деректер
    └── queries.sql # Мысал сұраулар
```

## Іске қосу

Каталог пен себет үшін `index.html` файлын браузерде ашу жеткілікті.

Тапсырыс беру үшін PHP және MySQL/MariaDB керек:

```bash
mysql -u root -p < db/schema.sql        # дерекқорды жасау
cp php/config.example.php php/config.php # және ішіне пароль жазу
php -S localhost:8000                    # серверді қосу
```

Содан кейін http://localhost:8000 мекенжайын ашыңыз.

> GitHub Pages тек статикалық файлдарды көрсетеді, PHP жұмыс істемейді.
> Сондықтан онда каталог пен себет жұмыс істейді, ал тапсырыс беру үшін PHP хостинг керек.

## Тауар қосу

`js/script.js` ішіндегі `PRODUCTS` тізіміне жаңа жол қосыңыз.
Бағаны `php/order.php` ішіндегі `$prices` тізімінде де жаңартыңыз.

## Дерекқор

```
categories 1 ──< products 1 ──< order_items >── 1 orders
```

- `categories` — тауар категориялары
- `products` — тауарлар (баға, сурет, белсенді ме)
- `orders` — тапсырыс беруші, мекенжай, жалпы сома, күйі
- `order_items` — тапсырыс құрамы; `unit_price` тапсырыс кезіндегі бағаны сақтайды
